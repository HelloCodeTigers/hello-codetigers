What we teach

Three big superpowers. Each one is learned by building, not just reading.

💻

Coding

Coding is like writing a recipe for a computer: clear steps it follows exactly.

  • Python basics
  • Websites with HTML & CSS
  • Making simple games
🤖

AI

AI is like teaching a computer by showing it lots of examples, the way you learn to spot a cat.

  • How AI learns
  • Using AI tools wisely
  • Building small AI projects
🔌

Physical Computing

This is code that leaves the screen and moves things in the real world: lights, sounds and motors.

  • Sensors and LEDs
  • Microcontrollers
  • Gadgets and mini robots

How a CodeTiger learns

Every project follows the same four simple steps.

1

Imagine

Think of something fun to make.

2

Build

Write code and put the parts together.

3

Test

Try it out. Bugs are just clues!

4

Share

Show your project to the world.
