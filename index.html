Why coding for kids?

Kids love code because it lets them create anything they can imagine. Along the way, it builds skills for life:

  • Problem Solving
  • Creativity
  • Reasoning
  • Teamwork & Collaboration
  • Computational Thinking

Coding is a foundational skill for the 21st century, just like reading and writing. Every child should get an opportunity to learn code.
